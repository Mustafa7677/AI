Multi-model AI · автоматты ауысу

Groq → Gemini → OpenRouter → Mistral → DeepSeek → OpenAI → Together → Cerebras → Fireworks. Серверде тек қосылған кілттер пайдаланылады.

API кілттерін бұл жерге жазбаңыз. Сервер құпиялары Cloudflare Worker ішінде сақталуы керек. Cloud режиміндегі хабарламалар сыртқы AI қызметтеріне жіберіледі.
