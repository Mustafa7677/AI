# TULPAR AI

Multilingual AI assistant for Kazakh, Russian and English with real Qwen/Ollama model streaming.

## Local launch

```bash
docker compose up --build -d
```

Open `http://localhost:8000` after the model and containers have started.

The application source consists of a FastAPI backend, responsive PWA frontend, Docker configuration, and automated tests. Optional image generation, cloud audio and web search require externally configured services.
